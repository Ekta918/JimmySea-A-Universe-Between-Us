# JimmySea | A Universe Between Us 💙✨

A dreamy, interactive fan-made website dedicated to Jimmy and Sea, celebrating their beautiful on-screen moments and projects.

### 🌷 Features
- Soft, aesthetic pastel design
- Interactive sky with floating flowers, butterflies, hearts, and stars
- About Jimmy and Sea
- Series and project gallery
- Memory gallery
- Fan letter section
- Hidden surprise message
- Responsive design for mobile and desktop

### 💻 Built With
- HTML
- CSS
- JavaScript
